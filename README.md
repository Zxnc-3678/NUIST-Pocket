# NUIST Pocket

南京信息工程大学校本部校园助手，支持本科生与研究生，使用Kotlin与Jetpack Compose开发。

0.9.0 新增跟随系统深色模式、临时停课与课表分享，并整理界面动效和新手帮助，见[使用说明](docs/0.9.0使用说明.md)。

课前提醒需单独允许系统“闹钟和提醒”，它与通知权限分开管理。版本变化见[更新记录](RELEASE_NOTES.md)。

**作者：仲夏南城 · 开发协作：ChatGPT**

本项目为同学自发开发的非官方应用，与学校无隶属关系。

设置中可切换本科生／研究生。两边分别保留课表、考试和导入数据，研究生模式隐藏教室入口，待办和外观设置共用。

## 功能

- **日程与课程表**：每日课程、一周总览、七天节次网格，支持跟手翻周动画、不连续周次、单双周、非本周课程，以及不同周次的教室和教师变化；今天上完的课程默认折叠，展开后灰色显示。
- **个人待办**：添加、编辑、完成或删除事项，支持日期、可选滚轮时间和备注；日程页固定入口，记录保存在本机，无需学校登录。
- **桌面小组件**：显示未结束的课程，课前15分钟提示，上课中倒计时；当天结束后预览明天，支持调整尺寸、独立高清背景图片、40%–95%淡化及底部未完成待办。
- **教室占用查询（本科生模式）**：支持明德、文德、滨江、揽江、阅江、临江六栋楼，完整加载分页，可按日期和节次筛选无占用标记的教室。
- **考试安排**：同步课程、时间、考场和座位，按状态筛选。
- **课前提醒与声音预约**：课前20分钟显示课程、地点与倒计时，支持锁屏；按次预约静音或勿扰，课前1分钟生效、下课后1分钟结束，默认关闭。
- **晚间提醒**：默认21:00预告明天的安排，48条问候按日期轮换，可改时间或关闭。
- **个性化**：分组设置、自选启动页面、六种预设主题色、自定义色号及本地课程表壁纸。

## 版本与下载

当前正式分享版为 **0.9.0**（versionCode35）。支持跟随系统深色模式；在日程日期右侧菜单设置临时停课；通过二维码或文件分享课表，收到的课表独立查看，可备注和删除。覆盖安装保留数据，升级后显示一次本地更新提示。见[0.9.0使用说明](docs/0.9.0使用说明.md)。

安装包以同学间分享的APK提供，开源发布后可从仓库的 **Releases** 下载。源码ZIP本身不能安装到手机。

最低支持Android11（API30）。部分功能曾在 Android 11 和 Android 16 设备上检查；不同厂商的桌面与省电策略可能影响小组件和提醒。

## 开始使用

1. 在右上角设置选择本科生或研究生，再打开学校账号，在学校原版页面完成认证，点击顶部“验证登录”。
2. 同步课表和考试后，可在日程或课程表查看；数据保存后可离线使用。
3. 本科生模式可在教室页选择楼栋、日期和节次，查询教室占用情况。
4. 在设置中选择启动页面、主题色和壁纸；到“课程与提醒”按需开启课前或晚间通知并按提示授权，也可添加桌面小组件。
5. 在日程标题旁点“待办”管理个人事项；设置 → 桌面小组件可选择背景图片、调整淡化程度或关闭底部待办。

没有登录时可以主动选择演示数据；演示课程、考试和教室均为虚构记录。设置中的“新手指引与帮助”可随时重看。

## 数据与权限

- 登录由学校原版HTTPS页面完成；App不读取或自行保存账号密码、验证码，不提供自动绕过统一认证的功能。
- App无自建中转服务或分析SDK；学校登录会话、课表、考试、个人待办和壁纸保存在本机私有目录，并排除系统备份与迁移。
- 学校会话需要重新验证时，已保存的课程与考试仍可查看；更新数据或查询教室需要有效学校会话。若门户登录仍有效，会尝试一次连接恢复。
- 选择壁纸使用系统文件选择器，图片不上传，不申请相册或存储广泛访问权限。
- 课表与考试只覆盖最近一次成功同步；教室查询不留历史。启动时仅清理超过24小时且未使用的壁纸导入临时文件，进出学校登录页时清理网页资源缓存；保留登录会话、离线安排、待办和已保存壁纸。
- Android13及以上发送通知需用户允许。课前提醒申请“闹钟和提醒”、声音与勿扰控制及声音设置权限；按次预约才会切换声音。晚间提醒与小组件仍可能受省电影响延迟，不依赖精确提醒授权。
- “无占用标记”不保证教室实际开放，请以现场为准。

## 构建

建议使用Android Studio，配置 **JDK21、Android SDK Platform36及Build Tools36.0.0**。

1. 克隆或下载源码，在Android Studio中打开仓库根目录。
2. 让Studio生成本机的`local.properties`，确认SDK路径和Gradle JDK。
3. 等待Gradle同步，运行`app`或构建APK。

项目固定使用Gradle8.13、AGP8.13.2和Kotlin2.2.21。

也可使用命令行，先配置`JAVA_HOME`及Android SDK（`ANDROID_HOME`或本机`local.properties`）：

```powershell
.\gradlew.bat assembleDebug
# 运行Kotlin单元测试与Lint
.\gradlew.bat testReleaseUnitTest lintRelease
# 完整检查和压缩后的APK；另需Node.js，开发时使用Node24
.\scripts\build.ps1 -Release -Check
```

macOS/Linux可使用`bash ./gradlew assembleDebug`，脚本测试可运行`node --test scripts/tests/*.test.cjs`。

产物位于`app/build/outputs/apk/`。为兼容早期同学分享包，当前Release配置仍使用开发机的debug签名；**自行构建会使用自己的签名，通常不能直接覆盖不同签名的已有安装包**。源码不包含作者的签名密钥。

## 检查与限制

项目包含 Kotlin 单元测试、Android 仪器测试和 JavaScript 脚本测试。可按“构建”章节在本地运行。具体设备与系统版本会影响通知、小组件和后台行为。

学校接口来自实际观察，并非学校提供的公开稳定 API。课程、教室和考试服务变更后，解析逻辑可能需要更新。目前面向南信大校本部本科生与研究生，校历覆盖范围及未核实情况以 App 内说明为准。
