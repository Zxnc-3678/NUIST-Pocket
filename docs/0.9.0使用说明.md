# NUIST Pocket 0.9.0

版本35，最低Android 11。使用原签名，可覆盖旧正式版或检查版安装并保留本机数据。

## 深色模式

App自动跟随手机系统的深色设置，无需额外开关。日程、课表、教室、考试、设置、待办、分享和弹窗共用主题配色。课程表壁纸遮罩随主题调整，课程全名继续完整换行。桌面小组件使用独立选择的背景，学校网页使用学校自己的配色。

## 临时停课

在日程选中日期，点日期右侧的三点“当天操作”菜单，选择当天全部停课。日期显示“已停课”；课程展示、小组件和相关提醒共同跳过这一天。需要恢复时在同一菜单恢复课程与提醒；已取消的声音预约需要重新预约。

## 分享与接收课表

进入设置的“面对面分享课表”，生成二维码，或通过系统分享一份课表文件。接收方在该页扫码或导入文件。二维码可能分为多张，需要全部扫描；文件不受二维码容量限制。生成起30分钟内可接收，已接收课表可继续查看。

收到的课表独立保存，不触发本人的课程提醒，可修改本机名称或备注，也可删除。当前保留一份收到的课表，再次接收会替换并清除旧备注。左侧日历和周次标题选择周次，右侧齿轮调整收到课表的显示。

## 提醒与权限

课前提醒默认关闭，需要时在“课程与提醒”开启，并到“权限与后台”检查通知、锁屏、准时提醒与声音授权。课程提前20分钟提醒，按次预约静音或勿扰，课前1分钟生效、下课后1分钟解除。仍使用安卓标准通知，厂商原生岛尚未接入。

## 本轮检查

在Android 36空白模拟器中实际查看明暗主题，检查深色日程、课表、教室状态、考试、设置和分享页，并确认可回切浅色。模拟器使用虚构演示数据，没有登录学校账号。本轮不代表各厂商手机全部验收。
