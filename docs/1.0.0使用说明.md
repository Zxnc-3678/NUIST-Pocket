# NUIST Pocket 1.0.0 使用说明

从 [GitHub Releases](https://github.com/Zxnc-3678/NUIST-Pocket/releases/tag/v1.0.0) 下载 APK。使用本项目提供的上一版 APK 的同学可直接覆盖安装。

## 换壁纸

在「设置 → 外观与启动 → 课表装潢」挑一个风格，或点壁纸库的加号添加图片。点缩略图立即预览，最多保存四张。已有的旧壁纸会进入第一格。

壁纸范围可选「仅课程表」或「全局沉浸」。两张起默认打开冷启动随机，可关闭开关，也可点「换一张」当场切换。

## 调整课程与待办

- 长按课块可改简称和配色、停一节或跨周调课。长按空白格，也可以手动添加课程。
- 已停掉的单节课可在「选择教学周 → 临时调整」恢复。普通教务同步会保留调整，退出或主动重新登录会清理当前培养类型的调整。
- 定时待办与课程按时间排在一起，全天待办有独立区域。点圆圈切换完成状态，点标题可编辑。

## 设置小组件与提醒

在「设置 → 桌面小组件」添加或调整小组件，卡片不透明度会统一应用。课前提醒的通知、准时提醒和锁屏权限可在「设置 → 权限与后台」查看。应用内的发布说明可在「设置 → 本次更新」重看。
